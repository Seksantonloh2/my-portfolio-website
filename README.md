# Northbridge Consulting — landing page

A modern, responsive landing page for a consulting business. Plain HTML, CSS and JavaScript — no build step.

- **Colours:** `#00296B` (navy), `#FFFFFF` (white), `#141414` (ink)
- **Fonts:** [Switzer](https://www.fontshare.com/fonts/switzer) for headings, [Inter](https://fonts.google.com/specimen/Inter) for body text

## Sections
Header · Hero · Client logos · Services · Approach · Results · Case studies · Testimonial · FAQ · Contact form · Footer

## Run locally
Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

The contact form only validates on the front end. Connect it to your backend or a form service (e.g. Formspree) in `script.js` before going live. The company name, copy, stats and contact details are placeholders to replace with your own.
